## Обязательные изменения

1. При выборе Эммы не запускать `introEventId` автоматически. Сразу открыть `mode: "location"`, `hero.location: "iron_bridge_village"`, `activeEvent: null`.
2. Локальная карта деревни должна быть видна сразу после выбора Эммы.
3. Клик по точкам локальной карты запускает события из `docs/07_EMMA_IMPLEMENTATION_SLICE_01.md`.
4. Локальные клики не тратят `actionsLeft`.
5. После локального события без `nextEventId` игрок должен возвращаться к локальной карте, а не идти по линейному сюжету.
6. Добавить/дополнить поддержку `condition`: `flag`, `notFlag`, `item`, `notItem`.
7. Добавить/дополнить поддержку `textVariants` через helper `getEventText(gameState, event)`.
8. Добавить эффект `inc_flag`, если его ещё нет.
9. Проверить `npm run build`.
