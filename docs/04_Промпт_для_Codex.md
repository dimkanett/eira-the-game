# Промпт для Codex: добавить системные параметры Разложения мира

Нужно доработать уже существующий прототип игры, а не переписывать его с нуля.

В проекте уже есть карта с точками, перемещение игрока по карте, интерфейс и базовая логика событий. Нужно аккуратно добавить слой игровой системы: Разложение мира, личное разложение героя и Sin.

## Цель доработки

Добавить в состояние игры три параметра:

```js
worldDecay
personalDecay
sin
```

## Требования

### 1. Не переписывать проект с нуля

Сохрани существующую структуру файлов, карту, точки и интерфейс.

Меняй только те файлы, которые нужны для добавления новой логики.

Если в проекте уже есть объект состояния игры, добавь параметры туда.

Пример:

```js
const gameState = {
  currentDay: 1,
  playerLocation: "...",
  worldDecay: 0,
  personalDecay: 0,
  sin: 0
}
```

Если структура другая — адаптируй под текущий код.

---

### 2. Добавить отображение параметров в UI

В блок статуса игрока добавить:

```text
День:
Разложение мира:
Личное разложение:
Sin:
```

Не перегружать интерфейс.

Журнал должен оставаться скрываемым.
Основное событие должно отображаться в центральном окне.

---

### 3. Добавить изменение Разложения мира после “Следующий день”

После завершения дня должна срабатывать функция мирового хода.

Пример логики:

```js
function processWorldTurn() {
  gameState.currentDay += 1;

  const decayChange = calculateDailyWorldDecayChange();
  gameState.worldDecay = clamp(gameState.worldDecay + decayChange, 0, 100);

  updateWorldByDecayLevel();
  renderUI();
}
```

Нужна функция `clamp`, чтобы значения не выходили за 0–100.

---

### 4. Добавить уровни Разложения мира

Сделать функцию:

```js
function getWorldDecayStage(worldDecay) {
  if (worldDecay <= 20) return "cracks";
  if (worldDecay <= 40) return "rot";
  if (worldDecay <= 60) return "collapse";
  if (worldDecay <= 80) return "fall";
  return "abyss";
}
```

Названия можно заменить на русские, если код проекта сейчас полностью русскоязычный.

---

### 5. Подготовить события к вариантам по Разложению

Для каждой точки события должны иметь возможность выбирать текст в зависимости от уровня Разложения.

Пример структуры:

```js
eventsByDecay: {
  cracks: "Деревня тревожна, но ещё жива.",
  rot: "Дети вернулись из леса, но говорят чужими голосами.",
  collapse: "Половина деревни поклоняется Новому Богу.",
  fall: "Деревня сожжена. В колодце слышен детский хор.",
  abyss: "Дома дышат. Деревня больше не человеческая."
}
```

Если сейчас у точки только одно событие, не ломай его. Добавь поддержку новой структуры так, чтобы старые события продолжали работать.

---

### 6. Добавить тестовое событие

Для одной существующей точки карты добавь пример события, которое меняется по уровню Разложения мира.

Нужно, чтобы можно было проверить:
- при низком `worldDecay` один текст;
- при высоком `worldDecay` другой текст.

---

### 7. Добавить временные кнопки отладки

Только для разработки добавить маленький dev-блок:

```text
+10 Разложение мира
-10 Разложение мира
+10 Личное разложение
+1 Sin
```

Если в проекте есть режим разработки — помести туда.
Если нет — добавь аккуратно внизу интерфейса и подпиши “dev”.

Потом эти кнопки можно будет убрать.

---

### 8. Не показывать игроку лишнее

Не добавлять:
- местоположение других героев;
- маршруты NPC;
- список всех мировых событий;
- подсказки “куда идти для главного квеста”.

Игрок должен видеть последствия, но не всю внутреннюю механику мира.

---

## Ожидаемый результат

После доработки:

1. В игре есть параметры `worldDecay`, `personalDecay`, `sin`.
2. Они отображаются в интерфейсе.
3. После следующего дня Разложение мира может меняться.
4. Есть функция определения стадии Разложения.
5. Событие хотя бы одной точки меняется в зависимости от Разложения мира.
6. Старый функционал карты и перемещения не сломан.
7. Код не переписан с нуля.
